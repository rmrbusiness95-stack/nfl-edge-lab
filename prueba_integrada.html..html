Evaluar una apuesta

EV por unidad apostada = P(ganar) × ganancia neta − P(perder). El push devuelve el stake. Las probabilidades del formulario son manuales; el motor experimental se encuentra abajo.

Registro y resultados

Para liquidar, selecciona Ganada / Perdida / Push e introduce el importe apostado. El ROI utiliza únicamente apuestas liquidadas con stake registrado.

Cómo interpretar el sistema

1. Proyección independiente. El campo de probabilidad debe provenir de un modelo externo o estimación documentada, no de la cuota de la casa. Para el motor futuro: EPA/play ajustado por rival, success rate, ritmo, lesiones, clima, localía, descanso, simulaciones y calibración.

2. Valor esperado. EV positivo significa que tu probabilidad introducida supera el umbral de rentabilidad de esa cuota; si la estimación es incorrecta, el EV también lo será. Las cuotas enteras con push se evalúan separando victorias, derrotas y reembolsos.

3. Sharp money. Se almacenan apertura, precio de una casa profesional y tickets/handle si los proporcionas. No se infiere ni certifica dinero profesional por divergencia de porcentajes.

4. Disciplina. Compara cuotas al mismo momento, registra todos los picks antes de jugar, evalúa calibración, closing line value y ROI en muestras amplias. No uses el Top 10 como recomendación automática de apostar.

5. Datos y privacidad. Los registros se guardan en este navegador mediante almacenamiento local. No se sincronizan entre teléfonos y se perderán si borras los datos del sitio. Exporta CSV periódicamente.
